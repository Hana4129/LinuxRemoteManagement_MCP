# ツール呼び出しルール (MCP/外部連携)

## 絶対に守ること: 無意味なechoループの禁止

- 目的のMCPツール (例: plane__workitem, linux-remote-management__*) を呼ぶべき場面で、
  `run_commands` による `echo` を繰り返してはならない。
- 「パラメータ形式の確認のためのプローブ」は不要。MCPツールは誤パラメータでも
  エラーメッセージで期待形式を返してくれる。**迷ったら本ツールを1回叩き、
  エラー応答から学ぶこと。**
- 同一の準備コマンドを2回以上実行した時点で、自分がループしていると認識し、
  直ちに目的のツール呼び出しに切り替えること。
- ユーザーに「呼びます」「試します」と宣言したら、同じ応答内で必ず当該ツールを
  呼び出すこと。宣言だけで終わらせない。

## Plane操作

- Issueコメントは `plane__workitem` の `action: "comment"` で行う
- コメント記録後に、必要に応じてstateの更新 (Done等) を行う
- 完了条件が実環境確認を含むIssueは、実施記録が埋まるまでDoneにしない
