Management Console

This console is bundled with the MCP Server (FastAPI). It calls each node's Linux Agent via HTTPS with Bearer Token and displays install status, OS version, uptime, etc.

API

  • GET /api/meta - app / servers / scopes metadata
  • GET /api/nodes - node list (status resolved)
  • GET /api/nodes/{id} - node detail
  • GET /api/tokens - token list (raw value hidden)
  • POST /api/tokens - issue token (raw value returned once)
  • POST /api/tokens/import - import externally issued token
  • GET /api/servers - list registered nodes
  • POST /api/servers - add a new node (+ optional token)
  • DEL /api/servers/{id} - delete a node (revokes related tokens)
