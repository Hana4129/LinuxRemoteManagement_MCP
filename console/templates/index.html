管理コンソール

このコンソールは MCP Server (FastAPI) に同梱されています。各ノードの Linux Agent に HTTPS + Bearer トークンで接続し、インストール状況・OS バージョン・稼働時間などを表示します。

認証・資格情報のフロー

本システムでは 3 種類の資格情報を使い分けています。それぞれ異なるタブで管理します:

資格情報使われる場面管理するタブ
MCP トークンMCP クライアント → MCP Server (Claude Desktop が MCP Server に認証)MCP Tokens
Agent credentialMCP Server → Linux Agent (ノードアクセス用の mTLS + Bearer トークン)Access → Agent credentials
コンソールセッションブラウザ → 管理コンソール (Basic 認証または OIDC ログイン)ログイン画面

Agent credential の登録は Agent ホスト上の credential-issue CLI で行います (コンソールに登録フォームはありません)。コンソールからは一覧・失効・削除のみ操作できます。詳細は doc/Operations.md を参照してください。

API

  • GET /api/meta — アプリ / サーバー / スコープのメタデータ
  • GET /api/nodes — ノード一覧 (ステータス解決済み)
  • GET /api/nodes/{id} — ノード詳細
  • GET /api/tokens — トークン一覧 (生値は非表示)
  • POST /api/tokens — トークン発行 (生値を1回だけ返す)
  • GET /api/tokens/{id}/reveal — トークン生値の再表示 (管理者のみ・監査ログに記録)
  • POST /api/tokens/import — 外部発行トークンのインポート
  • GET /api/servers — 登録済みノードの一覧
  • POST /api/servers — ノードの追加 (+ 任意でトークン発行)
  • DEL /api/servers/{id} — ノードの削除 (関連トークンを失効)
